Link WhatsApp?

Optional. You can link your own WhatsApp account and have messages shared between Ephemeral and WhatsApp when both people have linked WhatsApp.

Linking uses an unofficial WhatsApp Web client. WhatsApp may limit or ban accounts using automation. WhatsApp messages also pass through the bridge server, which must temporarily see plaintext to relay them.

Scan to link WhatsApp

Open WhatsApp → Settings → Linked devices → Link a device, then scan this code. After it connects, we'll send a code to your own WhatsApp chat to confirm the number.
